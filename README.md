# 🏙️ 3D Environment (Castelia City & 4K Sky)

A pure, interactive 3D WebGL environment built with **Three.js** and **Vite**.

## 🌟 Features
- **4K HDR Sky**: High dynamic range sky dome with realistic atmospheric clouds and image-based lighting.
- **3D Skyscraper City**: Castelia City 3D model with realistic textures, materials, and soft shadows.
- **Full 3D Navigation**:
  - **Left Click & Drag**: Rotate 360° around the city
  - **Right Click & Drag**: Pan camera across streets and towers
  - **Mouse Scroll**: Smooth zoom in and out
  - **Touch Support**: Full pinch-to-zoom, rotate, and pan on mobile/tablet.

## 🚀 Run Locally
```bash
npm install
npm run dev
```

## 🌐 GitHub Pages Deployment
This repository is configured with an automated GitHub Actions workflow (`.github/workflows/deploy.yml`).
Whenever changes are pushed to `main`, GitHub Pages automatically builds and publishes the live site.
